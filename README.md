# Salman Faris - Digital Product & UI/UX Designer Portfolio

A personal design portfolio website built with **React**, **Vite**, and **Vanilla CSS**. Features a floating card-based design over an atmospheric cloud sky backdrop, typography with dual stroked/solid headers, custom cutouts, interactive project modals, and project briefing forms.

## ✨ Features

- **Hero Section**: Dual typography lockup (`SALMAN FARIS`), cutout portrait integration, availability pill badge (`● Available for New Project`), and vertical social links.
- **Selected Work**: Filterable project gallery (`All`, `Real Project`, `Exploration`) with interactive case study drawers and verification metrics.
- **Services Showcase**: Hover rows with directional arrows for UI/UX Design, Web Design & Dev, Branding, and Motion & 3D.
- **Experience Timeline**: Dark theme (`#191919`) aesthetic displaying career milestones, senior product roles, and agency experience.
- **Contact Card & Modal**: Interactive project briefing modal with budget selection pills, service selectors, direct email copy with clipboard feedback, and celebration confetti.
- **Responsive & Widescreen**: Layout calibrated with fluid clamps up to `1600px` widescreen with breakpoints for tablet and mobile screens.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Micro-Interactions**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Typography**: Plus Jakarta Sans & Inter (Google Fonts)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/xalmanfaris/portfolio2.git

# Navigate into project directory
cd portfolio2

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` or the port shown in your terminal.

### Production Build

```bash
npm run build
npm run preview
```
